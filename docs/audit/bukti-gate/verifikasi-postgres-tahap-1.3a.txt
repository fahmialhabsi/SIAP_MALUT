   - Restart API: tidak seed ulang; kegiatan tetap 14 (data tahan restart)
   - psql "delete from log_audit"  -> ERROR: log_audit bersifat append-only: DELETE ditolak
   - psql "update log_audit ..."   -> ERROR: log_audit bersifat append-only: UPDATE ditolak
   - APP_MODE=production pada basis data berisi data contoh -> API menolak: "Mode production menolak mulai: terdapat 38 data contoh (is_contoh)."
